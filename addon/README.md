# Hermes Workspace Add-on

Hermes Workspace is an AI agent command center built directly into your Home Assistant environment. This add-on provides a fully integrated UI for interacting with your AI agent, including chat, files, memory, and skills.

## How it works

This add-on bundles two critical components:
1. **Hermes Agent**: A Python-based AI agent gateway that interfaces with your favorite LLM provider.
2. **Hermes Workspace**: A sleek, modern Node.js frontend UI that you interact with directly from your Home Assistant sidebar.

By leveraging Home Assistant's Ingress feature, you can interact with the agent without needing to expose any additional ports or manage separate authentication. Everything is handled securely by Home Assistant.
