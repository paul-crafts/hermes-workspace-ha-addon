# Changelog

## [1.0.0] - Initial Release
- Complete Home Assistant Add-on for Hermes Workspace.
- Multi-stage Docker build for optimized image size.
- Includes `hermes-agent` and `hermes-workspace`.
- Integrated Ingress support for sidebar access.
- Configuration options for LLM provider and API keys.
- Data persistence via Home Assistant's `addon_configs`.
